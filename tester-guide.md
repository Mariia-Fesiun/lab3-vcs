# Пам'ятка тестувальника
1. Завжди перевіряйте робочий каталог командою `git status` перед початком роботи.
2. Перевіряйте зміни через `git diff` перед додаванням у індекс.
3. Використовуйте зрозумілі повідомлення до комітів (наприклад, "fix: ..." або "docs: ...").
4. Перед відправкою на GitHub переконайтеся, що всі тести пройшли успішно.
5. Регулярно робіть `git pull`, щоб мати актуальну версію проєкту.
